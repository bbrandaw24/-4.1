## 1. 项目概述

本项目按照《中国地质大学 12 天实训计划》推进，目标是完成“设备模拟器 -> MQTT -> Flask API -> 数据与 AI 接口 -> 可视化页面 -> 鸿蒙 APP 映射”的端云智端闭环。本阶段已形成可运行的温室监控看板，并完成本地虚拟机和腾讯云公网环境验证。

当前成果包括：实时土壤湿度、温度、光照数据；10 小时趋势窗口；横纵坐标和单位；灌溉控制闭环；MQTT 回执；告警接口；概览、趋势、设备页面；公网同源网关。

## 4. 信号与控制闭环

设备模拟器每 5 秒发布传感器数据到 MQTT；Flask API 订阅消息并缓存最新状态；页面轮询 API 绘制实时和历史趋势。页面发送水泵动作后，API 生成 `command_id` 并发布 MQTT 指令，模拟器执行后回传 `status/pump`，API 收到回执后页面显示确认状态和响应耗时。

模拟器采用连续状态模型：灌溉运行时土壤湿度每 5 秒约增加 1.8 个百分点，停止后缓慢回落；温度、光照和空气湿度围绕基线小幅波动。

## 5. 验收结果

- 水泵启动、停止指令均收到 MQTT 回执。
- 灌溉复测：土壤湿度 `49.79% -> 56.95%`，16 秒增加 `7.16` 个百分点。
- 水泵停止确认延迟约 `2.6 ms`。
- 10 小时历史接口正常返回。
- 公网页面、设备接口、AI 状态接口均验证 HTTP 200。
