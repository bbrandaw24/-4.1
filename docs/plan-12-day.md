# 智慧农业 12 天执行计划

依据《中国地质大学12天.docx》中的第 1-12 天内容。与过时的“堵桥”任务无关。

| 天数 | 目标 | 关键交付物 | 状态 |
| --- | --- | --- | --- |
| 第 1 天 | 开题、架构、Docker 全栈环境 | SOW、架构设计、Compose、Git 规范 | 进行中 |
| 第 2 天 | 设备模拟器与 MQTT | 模拟器配置、数据规格、MQTT 协议 | 已完成（待 Docker 实机验收） |
| 第 3 天 | Flask 服务端与设备管理 | API 文档、设备接入、消息路由 | 已完成 |
| 第 4 天 | 图片上传与存储 | 上传接口、图片处理、存储配置 | 待开始 |
| 第 5 天 | AI 图像识别基础 | AI 需求、数据集标注规范 | 待开始 |
| 第 6 天 | 模型导出与业务集成 | 推理服务、结果存储、趋势逻辑 | 待开始 |
| 第 7 天 | 鸿蒙 APP 基础与可视化 | APP 结构、路由、数据展示 | 待开始 |
| 第 8 天 | APP 灌溉控制与 MQTT | 灌溉页面、MQTT 客户端、告警 | 待开始 |
| 第 9 天 | AI 展示与端云 APP 联调 | 视觉页面、联调记录、Bug 日志 | 待开始 |
| 第 10 天 | 集成测试与自动化规则 | 集成测试、灌溉规则、定时任务 | 待开始 |
| 第 11 天 | 安全、性能、运维 | 安全加固、性能报告、运维手册 | 待开始 |
| 第 12 天 | 工程文档与交付 | 详细设计、代码规范、部署文档 | 待开始 |

## 验收主线

设备模拟器产生传感器数据 -> MQTT 上报 -> Flask 接收 -> MySQL 持久化 -> APP 展示；图片上传 -> AI 推理 -> 数据库更新 -> APP 展示；APP 灌溉指令 -> MQTT -> 模拟执行器 -> 状态回传。
