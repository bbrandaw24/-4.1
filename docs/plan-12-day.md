## 已验证的验收主线

```text
模拟器传感器数据
    -> MQTT 主题
    -> Flask API 接收和设备状态
    -> Web 看板显示最新值和趋势

Web 水泵控制
    -> API command_id
    -> MQTT control/pump
    -> 模拟器状态变化
    -> MQTT status/pump
    -> API confirmed 和 latency_ms
```

云端还完成了 Mosquitto 发布/订阅实测，结果为 `MQTT_RESULT=PASS`。相应证据和说明见 [`project-completion.md`](project-completion.md) 与 [`../evidence/README.md`](../evidence/README.md)。
